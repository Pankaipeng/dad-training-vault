# 安全睡眠

> 结论：睡眠安全只有五条，每条都能救命，没有「我们家没事」的余地。

## 五条
1. 仰卧：每次睡都仰卧，不趴睡、不侧睡
2. 硬床垫：平整、硬实，不软塌
3. 同房不同床：睡小床，床靠大床，不同床睡
4. 床上空：无枕头、无被子、无床围、无毛绒玩具
5. 不趴睡：清醒时可以练趴，大人全程看着

## 环境
- 室温 22—26℃，摸后颈判断冷热，不看手脚
- 穿衣比大人多一件薄的就够，不捐
- 不用电热毯、不盖厚被、睡觉不戴帽子

## 大人这边
- 饮酒、服镇静药之后不同床
- 不睡沙发或软椅抱着孩子
- 夜里喂奶先把自己弄清醒，坐着喂
