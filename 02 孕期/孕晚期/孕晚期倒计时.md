# 孕晚期倒计时

> 预产期 2027 年 1 月。具体检查、复查、入院标准以建档医院安排为准，本页只管排事和打勾。

## 按孕周排

### 28–32 周
- [ ] 确认在哪儿生（医院 / 分院 / 特需），问清产科楼层和夜间急诊入口
- [ ] 把建档本、检查单、身份证扫描件存进手机相册一份
- [ ] 开始比月子方案：月子中心 / 月嫂 / 家里（见 [[月子方案对比]]）
- [ ] 问医院：待产包哪些他们提供、哪些必须自带

### 33–35 周
- [ ] 待产包按 [[待产包清单]] 买齐（27 件必备里还剩几件）
- [ ] 婴儿床 / 床品装好，衣物洗晒一遍
- [ ] 车加满油、办通行（如限行）、存好停车场路线
- [ ] 和公司确认陪产假天数与交接

### 36 周
- [ ] 待产包装箱放门口，分三袋：证件袋随身 / 进产房小包 / 住院箱
- [ ] 证件袋清单核对一遍（见 [[住院与路线]]）
- [ ] 手机存好：产科电话、急诊电话、司机/家人电话
- [ ] 家里留一把钥匙给能来帮忙的人

### 37 周起（足月）
- [ ] 每周产检，按医生要求做胎监
- [ ] 每天记胎动（时间和次数按医院教的方法）
- [ ] 出现破水、见红、规律宫缩等情况，按医院给的标准直接去，不自行判断

### 38–41 周
- [ ] 复查频率按医院安排
- [ ] 待产包再点一遍数（消耗品有没有被别的东西挪走）
- [ ] 过了预产期按医院要求复诊，不拖
