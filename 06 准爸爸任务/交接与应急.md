# 交接与应急

## 给外婆的一页纸

打印本节或抄到纸上。空白由爸爸和外婆现场确认，填好后留在家里。

- **白天**：外婆 ____ 至 ____；爸爸下班接手 ____；夜间当班 ____；备用 ____。妈妈先恢复，身体允许且愿意时搭手。
- **冲奶**：先开灯洗手，宝宝放小床。奶粉 ____，每 ____ mL 水配 ____ 平勺，实际冲调温度按儿科确认的 ____。先水后粉，冷却试温。喝过的剩奶倒掉，每次拆洗，晾干后收。
- **喂奶**：宝宝半坐着，托好头，慢慢喂。停吸、转头就暂停，别硬塞。医生说最长间隔 ____，叫醒安排 ____。喂完困了，仰卧放小床。
- **尿布与睡觉**：脏湿就换，从前往后擦，拍干再穿。小床不要枕头、被子或玩具，每次仰卧。换洗用品放 ____。
- **记录**：写时间、实喝多少、有没有尿和便、哪里不对。最后一餐 ____；今天尿布 ____；下次复查 ____。用 [[每日记录表]]。
- **马上叫 120**：宝宝发青、没反应、喘不过气、抽搐；妈妈大量出血、晕倒、胸痛气短、抽搐或有马上伤害自己或宝宝的危险。
- **马上去急诊**：宝宝未满 3 个月发热到 38℃，或吐绿水、喷射性呕吐；妈妈出血一小时湿透一片卫生巾、严重头痛或看东西异常。宝宝黄得更重或吃奶、尿布明显少，今天联系儿科；伴难叫醒直接急救。
- **电话和路线**：地址到楼栋门牌 ____；儿科急诊/夜间入口 ____；产科急诊 ____；社康 ____；爸爸 ____；备用成人 ____；出院小结和证件 ____。

## 交接检查

- [ ] 长辈照卡片冲一餐、瓶喂、换尿裤并把宝宝仰卧放回床。
- [ ] 独立填写一条记录，能用自己的话复述 120 和急诊信号。
- [ ] 用模拟人随导师练婴儿急救；家人都知道 [[呛奶急救]] 入口。
- [ ] 爸爸确认复工时间、白天/夜间负责人及替班人；复查和药物已明确。
- [ ] 负责的人知道夜间出门路线，能向 120 报地址和呼吸状态；手机有电。
