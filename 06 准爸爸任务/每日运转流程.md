# 每日运转流程

> 结论：把一天切成班次，不是「谁有空谁上」。

## 独自版（产后第 16 天起）

| 时间 | 谁 | 做什么 |
| --- | --- | --- |
| 06:30 | 你 | 换尿布 → 喂 → 拍嗝；07:30 做早饭 |
| 08:00—09:00 | 你 | 妈妈回笼觉，你带娃、洗衣 |
| 10:00—11:30 | 你 | 补觉，硬性，不能省 |
| 13:00—15:00 | 你 | 妈妈午睡，你带娃，推车出门 30 分钟 |
| 16:00—17:30 | 你 | 备晚饭、消毒奶瓶、采购 |
| 18:00 | 你 | 喂奶，隔天洗澡 |
| 19:00 | 妈妈 | 吃饭、洗澡、睡 |
| 21:00—02:00 | 你 | 值夜，含 1—2 次喂 |
| 02:00—07:00 | 妈妈 | 值夜，你睡整段 |

## 有长辈搭手版
- 21:00—24:00 你值班，妈妈先睡 3 小时
- 24:00—05:00 妈妈值班
- 05:00—08:00 长辈早班，妈妈接着睡到 8 点
- 21:00 以后不叫长辈，让她睡整觉

## 三条硬规则
- 每人每晚一段连续 5 小时，这是底线不是奢侈
- 你的补觉写进日历，不「有空再睡」
- 交接只看 [[每日记录表]]，不靠记忆
