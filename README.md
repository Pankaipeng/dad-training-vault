# 准爸爸培训 · Obsidian 库

> 从备孕到产后第 16 天独立带娃，按阶段整理的个人笔记库。备份用，请勿公开。

## 怎么用

- 用 Obsidian「打开文件夹作为仓库」选中本目录即可
- 从 [[首页]] 开始，完整导航见 [[知识库索引]]
- 目录约定、标签规则、六周计划用法见 [[库结构说明]]

## 结构

- `00 收件箱` — 临时记录，每周清空
- `02 孕期` — 产检、孕晚期倒计时
- `03 分娩` — 待产包、住院与路线
- `04 产后` — 月子与恢复、回奶
- `05 新生儿` — 喂养与睡眠、日常护理、常见问题
- `06 准爸爸任务` — 任务清单、六周上岗计划、每日运转、交接与应急
- `07 采购与预算`
- `08 课程与资料` — 书单、课程与视频
- `99 归档` — 已过的阶段

## 说明

- 本库只做个人记录与资料整理，具体检查、用药、喂养以医生和医院安排为准
- 笔记名用短标题；状态标签 #待办 #已读 #重要 #待问医生
