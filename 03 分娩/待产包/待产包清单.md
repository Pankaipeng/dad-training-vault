# 待产包清单 · 必备待买

只收**必备**且**还没买**的：共 27 条，去重后 26 件东西。买一件勾一件。

## 妈妈 · 卫生护理（7 件）

- [ ] 产褥垫 60×90cm（30 片）— 买多的可以给宝宝当隔尿垫
- [ ] 一次性内裤（棉质高腰，20 条）— 一定要高腰，低腰会勒剖腹产伤口
- [ ] 安睡裤（3 包）— 产后头两天恶露最多，比卫生巾省事
- [ ] 夜用卫生巾 420mm（2 包）— 第 3 天以后用
- [ ] 日用卫生巾 240–250mm（2 包）— 出院前后用
- [ ] 私处冲洗器（1 个）— 每次如厕温水冲，顺产剖腹产都用得上
- [ ] 一次性马桶垫（20 片）— 多人病房必备，1 片 1 次

## 妈妈 · 衣物（9 件）

- [ ] 哺乳睡衣／前开扣家居服（2 套）— 前开扣才方便喂奶，套头款别带
- [ ] 出院便服（1 套）— 宽松为主，1 月选厚一点的
- [ ] 厚外套（1 件）— 深圳 1 月湿冷，去做 B 超、出院路上穿
- [ ] 哺乳文胸（2 件）— 装箱：回家再用；住院基本不穿，出院后开始用
- [ ] 月子帽／出院帽子（2 个）— 病房空调冷气足，出院必戴
- [ ] 包跟棉拖鞋（1 双）— 1 月别穿露跟的，脚一凉就难受
- [ ] 防滑洗澡拖鞋（1 双）— 淋浴用，一定要防滑
- [ ] 袜子（3 双）— 棉质，换洗够用
- [ ] 收腹带（1 条）— 剖腹产必用；顺产产后 3 天可开始，吃饭睡觉取下

## 妈妈 · 洗漱日用（4 件）

- [ ] 洗漱包（软毛牙刷／牙膏／漱口杯／洗面奶，1 套）— 软毛，产后牙龈敏感
- [ ] 毛巾（2 条）— 擦脸、擦身分开
- [ ] 洗脸盆（1 个）— 选能叠放的，省地方
- [ ] 护唇膏（1 支）— 装箱：进产房小包；产程和术后嘴唇干裂，很多人漏带

## 妈妈 · 药品护理（2 件）

- [ ] 胎监带（2 条）— 产检就在用，住院还要接着用
- [ ] 双氯芬酸钠栓（1 盒）— 剖腹产／侧切止痛神器，用前必须问医生

## 宝宝 · 喂养（1 件）

- [ ] 婴儿湿巾（3 包）— 消耗最大的东西之一

## 宝宝 · 洗护（1 件）

- [ ] 小盆（2 个）— 洗脸、洗屁屁必须分开

## 宝宝 · 出行（1 件）

- [ ] 安全提篮／安全座椅（1 个）— 深圳出院上车必须用，交警查后排安全座椅（原表备注写「不买」，需确认是否借用）
